# กลับเข้า Space ล่าสุด

เมื่อเลือก **เข้า Space** เว็บจะจำ Space นั้นแยกตามบัญชี Google ใน Neon (`public.hvr_workspace_preferences`) หลังออกจากระบบแล้ว Login ใหม่จะกลับเข้า Space ล่าสุดได้ โดยยังต้อง Login ตามอายุ session เดิม

- หลังอัปเดตรุ่นนี้ ให้เลือก Space หนึ่งครั้งเพื่อบันทึกค่าเริ่มต้น
- เปลี่ยนทีมได้จากเมนู **เลือก Space / เปลี่ยน Space** หน้าเลือกยังเปิดได้ตามปกติ
- ลิงก์ที่ระบุ Space เช่นลิงก์งานจาก LINE ยังเปิดหน้าเลือก Space ตามลิงก์ ไม่ถูกแทนด้วย Space ล่าสุด
- หากไม่มีประวัติ หรือ Space/สมาชิกถูกปิดหรือถอนสิทธิ์ ระบบกลับไปให้เลือก Space
- การจดจำใช้กับเว็บเท่านั้น ไม่เปลี่ยน Space ที่เลือกไว้สำหรับ LINE AI
- อุปกรณ์ที่มี session อยู่แล้วคง Space ที่เลือกใน session นั้น ส่วน Login ครั้งใหม่ใช้ค่าล่าสุดของบัญชี

## การติดตั้งและกู้กลับ

ใช้ migration `014_workspace_preferences.sql` กับฐานข้อมูลกลางก่อน deploy เว็บ โดยรัน `npm run db:migrate` จาก `web/` ด้วย configuration ของ environment ที่ถูกต้อง ตารางนี้ไม่ต้องเพิ่มใน Airtable และไม่รวมใน operational schema ของแต่ละ Space

Migration เพิ่มตารางใหม่โดยไม่แก้ข้อมูลงาน การ rollback เว็บไป release ก่อนหน้าในระบบหลาย Space ทำได้โดยคงตารางนี้ไว้ ห้าม rollback ไป release ก่อนรองรับหลาย Space หรือย้อนฐานข้อมูลสดเพื่อยกเลิก preference เพียงอย่างเดียว

ข้อมูลที่จำไม่ใช่สิทธิ์เข้าถึง: ทุกครั้งต้องตรวจ Users.Active, membership, Space และ Base binding ใหม่ การสลับบัญชีผ่าน OAuth จะตั้ง cookie ตามบัญชีใหม่หรือล้าง cookie ของบัญชีเดิม และคำขอจากแท็บที่ใช้ Space คนละตัวกับ session ยังคงถูกปฏิเสธ
