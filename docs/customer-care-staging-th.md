# แผนดูแลลูกค้าตลอดอายุกรมธรรม์

หน้า **ดูแลลูกค้าและกรมธรรม์** อยู่ในแต่ละ Space ที่ `/{space}/customer-care` จุดเริ่มงานของเลขาคือคิววันนี้ เมื่อลูกค้าต้องการคุยเรื่องความคุ้มครอง ให้ส่งต่อพร้อมวันนัดและประเด็นที่ลูกค้าต้องการให้ช่วย ตัวแทนเปิดดูกรมธรรม์และนัดของลูกค้าที่ตนดูแลได้จากเมนูเดียวกัน

## 1. ข้อมูลและสิ่งที่ทีมต้องติดตาม

- บันทึกชื่อลูกค้า รหัสอ้างอิง ประเภทกรมธรรม์ ตัวแทนเจ้าของ วันเริ่ม และวันครบสัญญาหรือวันชำระครั้งถัดไปเมื่อทราบ ลูกค้าคนเดียวมีหลายกรมธรรม์ได้ ให้ตรวจรหัสอ้างอิงก่อนบันทึกผลแต่ละครั้ง
- เลขาตรวจว่าลูกค้าได้รับเอกสาร รู้ช่องทางใช้สิทธิ ติดต่อทีมได้ และได้รับคำตอบเรื่องบริการหรือเคลม บันทึกสรุปสั้น ๆ เช่น “สะดวกคุยกับตัวแทนวันศุกร์” เก็บเอกสารและข้อมูลสุขภาพละเอียดในช่องทางของบริษัท
- ตัวแทนทบทวนผู้พึ่งพิง ภาระครอบครัว เป้าหมาย หรือการเปลี่ยนอาชีพตามที่ลูกค้าต้องการพูดคุย บันทึกผลได้ทั้ง “ดูแลต่อแบบเดิม” หรือ “นัดทบทวนเพิ่มเติม” การติดต่อบริการถือว่าสำเร็จได้โดยไม่ต้องเสนอขาย

## 2. แผนตามช่วงชีวิตของกรมธรรม์

| จังหวะ | เลขาทำอะไร | ผลที่ควรบันทึก |
|---|---|---|
| เริ่มคุ้มครอง | ประสานส่งมอบและแนะนำช่องทางติดต่อ | ยืนยันการรับเอกสาร หรือกำหนดวันติดต่อซ้ำ |
| ประมาณ 30 วันหลังเริ่ม | ถามว่ายังมีข้อสงสัยหรือใช้บริการได้ไหม | คำถามที่ต้องตอบและผู้รับช่วง |
| ระหว่างปี | เพิ่มนัดเมื่อย้ายงาน มีบุตร มีผู้พึ่งพิงใหม่ หรือหลังแจ้งเคลม | นัดตามความสะดวก ส่งให้ตัวแทนเมื่อจำเป็น |
| ก่อนชำระเบี้ย | ตรวจวันตามเอกสาร ประสานตัวแทนและตรวจผลชำระ | เมื่อยืนยันแล้วลงวันรอบถัดไป หากติดต่อไม่ได้ให้ตั้งวันติดตาม |
| รอบปีกรมธรรม์ | นัดทบทวนสิทธิ ข้อมูลติดต่อ และการเปลี่ยนแปลงในชีวิต | เมื่อจบรอบ ระบบสร้างนัดครบรอบถัดไปภายในอายุสัญญา |
| ก่อนครบสัญญา | ตรวจเอกสารและการรับผลประโยชน์กับบริษัท | ยืนยันว่าดูแลครบ แล้วให้เลขาหรือ Admin กดสิ้นสุดการติดตาม |

กรมธรรม์เก่าที่นำเข้าหลังช่วงต้อนรับจะเริ่มด้วยนัดบริการในปัจจุบันและรอบทบทวนถัดไป กรมธรรม์ที่เลยกำหนดต้องให้ทีมตรวจสถานะจริงกับบริษัทก่อนสรุปว่าขาดอายุ

## 3. ประเด็นตามประเภทประกัน

| ประเภท | สิ่งที่ตัวแทนควรทบทวนกับลูกค้า |
|---|---|
| ชีวิต | ผู้รับประโยชน์ ภาระครอบครัว และข้อมูลติดต่อ |
| สุขภาพ | วิธีใช้สิทธิ ช่องทางเคลม และผลประโยชน์ที่ระบุในแผน |
| โรคร้ายแรง | เงื่อนไขผลประโยชน์ และช่องทางประสานเมื่อขอรับบริการ |
| อุบัติเหตุ | อาชีพหรือกิจกรรมที่เปลี่ยนไป และขั้นตอนแจ้งเหตุ |
| สะสมทรัพย์ / บำนาญ | กำหนดรับเงินตามสัญญาและความพร้อมของช่องทางรับเงิน |
| ยูนิตลิงค์ | นัดผู้ดูแลที่เหมาะสมเพื่อทบทวนรายงาน ค่าใช้จ่าย และเป้าหมาย |

ทีมตรวจแบบฟอร์มที่เกี่ยวกับงานบริการจาก [คลังแบบฟอร์ม Allianz](https://www.allianz.co.th/th_TH/services/form-download.html) และยึดวันกับเงื่อนไขตามเอกสารของกรมธรรม์แต่ละฉบับ

## 4. การเตือนและผู้รับผิดชอบ

Staging ใช้คิวแจ้งเตือนในเว็บ เวลาไทย จัดรายการเกินนัดไว้ก่อน เริ่มเตือนก่อนชำระเบี้ยหรือทบทวนรายปี 30 วัน ก่อนครบสัญญา 60 วัน และก่อนนัดบริการทั่วไป 7 วัน ส่วนวันส่งมอบแสดงเมื่อถึงกำหนด ระยะเหล่านี้เป็นค่าเริ่มต้นสำหรับการทำงานของทีม หน้าเว็บตรวจใหม่เมื่อเปิด กลับเข้าแท็บ และทุกห้านาทีขณะเปิดใช้งาน

เลขาและ Admin เห็นคิวทั้ง Space ส่วน Agent เห็นเฉพาะกรมธรรม์ของตน เลือกผล **ดำเนินการแล้ว**, **ติดต่ออีกครั้ง** หรือ **ส่งต่อตัวแทน** สองตัวเลือกหลังต้องระบุวันนัดใหม่ ประวัติผลเดิมยังเปิดดูได้ การกดสิ้นสุดการติดตามนำกรมธรรม์ออกจากคิวและเก็บไว้ในทะเบียน

## ทดลองบน Staging

1. เปิด Space ทดสอบ เลือก **ดูแลลูกค้าและกรมธรรม์ → เพิ่มกรมธรรม์** ใช้ชื่อ “ลูกค้าทดลอง A” และรหัส “DEMO-CARE-01” เลือกตัวแทนจริงของ Space ทดสอบ ใส่วันเริ่มเมื่อวานและวันชำระเบี้ยอีก 7 วัน
2. เปิดคิว ตรวจว่ามีนัดส่งมอบและเตือนชำระเบี้ย กดรายการเพื่อดูกรมธรรม์และคำแนะนำเฉพาะประเภท
3. ในกรมธรรม์ เพิ่มนัด **ทบทวนเมื่อชีวิตเปลี่ยน** เลือกผู้ติดตาม กดนัดนั้น เลือก **ส่งต่อตัวแทน** และกำหนดวันพรุ่งนี้ ตรวจประวัติและคิวใหม่ด้วยตัวแทนเจ้าของ
4. ทดลองจาก Agent คนอื่นหรืออีก Space ตรวจว่ามองไม่เห็นกรมธรรม์นี้ ให้เลขาปิดการติดตามเมื่อจบการทดลอง

ก่อนขยายการใช้งาน ให้ทีมลองหนึ่งรอบสัปดาห์และดูว่ากี่นัดเกินกำหนด กี่เคสยังรอยืนยันการชำระ และกี่นัดส่งต่อแล้วมีผลติดตาม ขั้นถัดไปที่เสนอคือสรุปคิวรายวันผ่าน LINE ให้เจ้าหน้าที่ที่ผูกบัญชีและเปิดรับแจ้งเตือน โดยกำหนดเวลา ผู้รับ และการป้องกันข้อความซ้ำกับทีมก่อนเปิดส่งจริง ข้อมูล Staging รอบนี้อยู่ใน Neon แยกตาม Space ผ่าน migration 017
